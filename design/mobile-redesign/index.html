What needs to change

The issue is hierarchy, not decoration.

01

The month became a spreadsheet

Thirty-one day rows multiplied by every habit, abbreviated labels, and two-axis scanning make patterns hard to see.

Redesign principle

Show one useful question at a time: overall rhythm, one habit, or one week.

02

Maintenance is always switched on

Rename fields, polarity toggles, drag handles, delete, and archive compete in every habit row—even when the user only wants to look.

Redesign principle

Default to a clean roster. Reveal destructive and reordering controls after Edit.

03

Sync exposes implementation

Server configuration, account state, device pairing, and everyday status appear as one undifferentiated settings page.

Redesign principle

Make sync automatic and quiet; move custom server setup under Advanced.

Borrowable fragments

Twelve more ideas worth stealing.

These can be mixed into any direction without adopting its full visual system.

MonthTwo-level calendar

Start with daily completion density; tap a habit to recolor the same calendar around that habit.

MonthWeek accordion

Five compact week summaries; expand only the week the user is investigating.

MonthHabit small multiples

One tiny 31-dot strip per habit—labels stay readable while patterns line up vertically.

TodayOne-thumb queue

Bring the next unfinished habit into the thumb zone; completed habits recede upward.

TodayLong-press yesterday

Offer a forgiving shortcut to backfill yesterday without turning Today into a date picker.

TodayCompletion undo

Mark instantly, then show a small undo toast. Fast interaction, no confirmation ritual.

HabitsView / Edit contract

Keep normal rows clean. Enter a named edit mode before showing handles or destructive actions.

HabitsSwipe to archive

Keep delete inside habit details; make the reversible action easier than the irreversible one.

SyncCloud status pill

A tiny header pill handles reassurance. The full sync screen appears only when tapped.

SyncIncoming change receipt

After sync, say “3 entries received from reMarkable” instead of reporting an implementation state.

PairingQR plus short code

Camera for speed, six characters for reliability, device-name verification for trust.

NavigationThree-tab ceiling

Today, Review, Settings. Habit management and devices become destinations, not permanent tabs.

Recommended sync experience

Ask people to connect devices—not configure sync.

The backend remains the authority and the app remains local-first. The interface simply reveals those facts in a safer order.

Default Automatic after sign-in

Sync after edits, on app foreground, and when connectivity returns.

Fallback Manual “Sync now” remains

Useful for reassurance and recovery, but no longer the primary workflow.

Advanced Custom server is optional

Validate the endpoint before saving it; keep self-hosting fully supported.

Suggested path forward

Build Quiet Focus, steal the best parts of Tiny Multiples.

Quiet Focus best fixes the information architecture: three primary tabs, progressive habit editing, and sync that stays out of the way. Its aggregate calendar is the friendliest default month overview, while Tiny Multiples is the strongest dense alternative. Let a user tap a habit to enter Habit Lens, and apply Clarity Max’s explicit labels and target sizes throughout.
