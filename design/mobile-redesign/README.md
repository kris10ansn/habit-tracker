# Habit mobile redesign study

A standalone, dependency-free gallery of twenty-five complete mobile redesign directions.

- **Quiet Focus** — moderate and recommended
- **Habit Lens** — moderate and data-forward
- **Pocket Journal** — expressive but practical
- **Orbit** — experimental radial interface
- **Living Garden** — playful, metaphor-driven wild card
- **Native Calm** — restrained platform-native utility
- **One Thing** — one-habit-at-a-time focus mode
- **Bento Board** — modular dashboard
- **Tiny Multiples** — analytical small-multiple month view
- **Glass Stack** — layered translucent surfaces
- **Raw Ledger** — blunt, brutalist record keeping
- **Clarity Max** — explicit, high-accessibility design
- **Pixel Pal** — habit tracker as handheld game
- **Habit Transit** — habits and devices as transit lines
- **Cut & Keep** — tactile collage and zine direction
- **Mixtape** — habits as a daily track list
- **Weather Maker** — consistency expressed as a changing climate
- **Habit House** — habits occupy rooms in a living home
- **Mission Control** — a spaceflight console for daily routines
- **Ritual Deck** — a symbolic card-based habit practice
- **Deep Sea** — habits as creatures in a bioluminescent aquarium
- **Comic Quest** — progress told through sequential panels
- **Clockwork** — an intricate mechanical instrument
- **Topographic** — consistency rendered as terrain and trails
- **Cellular Bloom** — completed entries grow a generative organism

Each direction includes Today, Month, Habits, Sync, Linked devices, and Link device. The gallery
also includes twelve smaller interaction ideas, a revised end-to-end sync flow, sync-state language,
and a recommendation matrix.

Open `index.html` directly, or serve this directory locally:

```sh
python3 -m http.server 4173 --directory design/mobile-redesign
```

Then visit <http://localhost:4173>. The page uses no external fonts, images, frameworks, or network
requests.
